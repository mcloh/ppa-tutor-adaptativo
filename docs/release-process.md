# Processo de revisão pré-publicação

## Regra operacional

Novas versões do PPA devem ser salvas como checkpoint e apresentadas ao responsável pelo projeto para revisão. A publicação automática permanece desativada.

## Sequência obrigatória

1. Executar verificações de tipos, testes e compilação quando aplicável.
2. Salvar um checkpoint com descrição objetiva das alterações.
3. Informar a versão e os fluxos validados, sem declarar a versão publicada.
4. Aguardar confirmação explícita do responsável para disponibilização pública.
5. A publicação, quando aprovada, será acionada pelo responsável na interface de gerenciamento do projeto.

## Escopo da revisão

A revisão deve considerar funcionalidade, experiência em dispositivos relevantes, dados sensíveis, preços, textos comerciais e integrações externas. Mudanças de pagamento, autenticação, conteúdo pedagógico ou cache reutilizável exigem atenção reforçada.
